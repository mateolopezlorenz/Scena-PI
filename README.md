# Scena

Scena es una aplicación web tipo SPA (Single Page Application) desarrollada como proyecto intermodular del CFGS de Desarrollo de Aplicaciones Web (DAW).

La plataforma permite descubrir eventos de ocio en Mallorca mediante un mapa interactivo, facilitando la visualización geográfica y mejorando la experiencia de usuario frente a sistemas tradicionales basados en listas.

---

## Tecnologías utilizadas

### Frontend
- Angular
- TypeScript
- HTML5
- CSS3
- Bootstrap
- Leaflet (mapas)

### Backend
- Java
- Spring Boot
- Spring Security
- JPA / Hibernate
- Maven

### Base de datos
- PostgreSQL

### Infraestructura
- Docker
- API REST

---

## Funcionalidades principales

- Visualización de eventos en mapa interactivo
- Filtrado por categoría, fecha y ubicación
- Consulta de detalles de eventos
- Gestión de eventos mediante API REST
- Arquitectura cliente-servidor
